## 3. Three Principles for Executable Policy

1. **Recovery is external, not self-certified.**
   `#PETER_ZEN` exits only through an external handshake: a `#GUARDIAN_MODE` ping, the Architect's resume command, or a verified source check. The specific external controller depends on the failed organ (see last column).

2. **Eviction is not deletion.**
   `f_V` moves stale memory to cold storage (`M_0`). The agent retains the reference, not the full text, preventing context bloat (Issues #1737, #1669).

3. **The gap remains undefined.**
   All mechanisms operate on `M_0` and `M_1`. `d(M_2)` is not a value; it is a horizon. It stays outside self-modification.
